# Протокол внешнего представления 16-зонного анализа бизнеса

Дата решения: 2026-08-05
Статус: принято
Связанная задача: #339

## Внешний термин

Основное название клиентского раздела:

**Комплексный анализ бизнеса по 16 ключевым зонам**

Подзаголовок:

**Системная карта компании: взаимодействие с рынком, люди, технологии и управление.**

Краткая форма для вкладки или навигации:

**Карта бизнеса по 16 зонам**

Коммерческое название услуги:

**Комплексная бизнес-диагностика**

## Запрещённые внешние термины

Не выводить в клиентский UI и экспорт:

- «Бизнес-машина AIMETON 4×4»;
- «Профиль бизнес-машины по каноническому КМ»;
- «КМ» и «канонический КМ»;
- иные внутренние названия методологии AIMETON.

Эти обозначения относятся к внутреннему уровню применения AIMETON. В коде допускается сохранить `business_machine_4x4`, но presentation layer обязан преобразовать его в утверждённый внешний словарь.

## Контракт представления

1. Блок анализа по 16 зонам присутствует в основном отчёте ровно один раз.
2. Основное представление — единая компактная карта/матрица 4×4, максимум две страницы.
3. Каждая зона содержит:
   - краткий вывод;
   - статус и уверенность;
   - коммерческое значение одной строкой.
4. Подробные источники, evidence и методологические пояснения выносятся в приложение или раскрываемый экспертный слой.
5. Не допускается повторная генерация одного массива 16 зон двумя PDF-шаблонами.

## Поверхности применения

Единый словарь обязателен для:

- stage и production UI;
- PDF;
- DOCX;
- Markdown;
- клиентских API payloads и schema labels;
- коммерческих презентаций и демо.

## Acceptance criteria

- Пользователь видит «Комплексный анализ бизнеса по 16 ключевым зонам» либо «Карта бизнеса по 16 зонам».
- В клиентском результате отсутствуют внутренние термины AIMETON.
- Все 16 зон сохранены без дублирования.
- Основной блок занимает не более двух страниц.
- Snapshot/regression-тест проверяет заголовок, отсутствие внутренних терминов и отсутствие второго набора 16 зон.
