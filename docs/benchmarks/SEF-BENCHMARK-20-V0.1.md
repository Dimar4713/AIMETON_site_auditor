# SEF Benchmark-20 v0.1

## Назначение

`SEF-BENCHMARK-20` — замороженная приёмочная выборка для развития AIMETON Search & Evidence Fabric. Она проверяет не красоту текста LLM, а способность системы:

- обнаружить правильную организацию;
- отделить бренд от юридического лица;
- найти официальный домен;
- получить проверяемые документы;
- сформировать claims без превращения поискового сниппета в evidence;
- явно показать `not_found`, противоречие или деградацию;
- измерить время и стоимость миссии.

Машиночитаемые файлы:

- [`benchmark-20-v0.1.json`](../../benchmarks/sef/benchmark-20-v0.1.json) — состав 20 компаний;
- [`golden-5-v0.1.json`](../../benchmarks/sef/golden-5-v0.1.json) — ручной эталон идентичности первых пяти компаний.

## Состав выборки

В выборке ровно четыре отрасли по пять компаний:

| Отрасль | Назначение |
|---|---|
| HVAC | Региональные компании со слабым и средним цифровым следом, сложным подбором и неочевидной связью бренд ↔ юрлицо |
| Стоматология | Клиники и сети, где нужны лицензии, филиалы и строгая граница медицинских выводов |
| Логистика | Национальные сети с брендом, филиалами и несколькими юридическими контурами |
| IT-инфраструктура | Провайдеры с сильным цифровым следом, реорганизациями и несколькими продуктовыми юрлицами |

Выборка содержит `low`, `medium` и `high` уровни цифрового следа. `sample_scale` — страта тестовой выборки, а не юридическая квалификация размера предприятия.

## Ручной эталон Golden-5

Для `SEF-B20-01`…`SEF-B20-05` вручную проверены:

- полное юридическое наименование;
- ИНН;
- ОГРН;
- официальный домен;
- медицинская лицензия для Sib Dental Clinic.

Каждый факт имеет прямую first-party ссылку, дату доступа, locator и уровень `T2_official_company`. Поисковая выдача использовалась только для discovery и не сохранена как evidence.

Эталон содержит только относительно стабильные identity-факты. Финансы, численность, руководство, адреса, рейтинги, вакансии и новости должны проверяться заново во время каждой кампании и не сравниваться побитово.

## Владелец и изменение

Владелец: `AIMETON Site Auditor / SEF-P0`.

Версия `0.1.x` запрещает менять состав компаний, отрасль, ожидаемую идентичность и обязательные типы фактов. Для такого изменения требуется:

1. новая minor-версия;
2. PR с обоснованием;
3. новые source evidence;
4. результат регрессионного теста;
5. описание влияния на сравнимость прошлых кампаний.

Patch-версия допускает только исправление опечаток и обновление доступности источника без изменения смысла.

## Правила будущей ATS-09B

Каждый запуск должен сохранять:

- service SHA;
- schema и benchmark versions;
- provider registry version;
- результаты по каждому case ID;
- precision/completeness для Golden-5;
- доказанный `not_found`;
- число противоречий;
- document success и browser fallback;
- p50/p95 времени;
- provider, LLM и browser cost;
- JSON, JUnit и Markdown summary.

Нельзя автоматически обновлять эталон под фактический ответ системы ради зелёного CI.
