# Решение владельца: использование бесплатных квот Tavily и Yandex на stage

Дата: 2026-08-06
Статус: принято
Связанные задачи: #293, #336

## Решение

Владелец AIMETON разрешил фактические вызовы Tavily и Yandex Search на stage в пределах их бесплатных квот для разработки, диагностики, испытаний и приёмки Site Auditor.

## Ограничения

- Разрешены только бесплатные квоты и уже существующие учётные данные.
- Автоматическое превышение бесплатного лимита и переход на платное потребление запрещены.
- Провайдер обязан иметь локальный quota/circuit-breaker и typed состояние `quota_exhausted`.
- Секреты, заголовки и сырые provider payloads не публикуются.
- Production-включение требует отдельной приёмки; настоящее решение относится к stage.

## Операционное следствие

- `not_configured` для Tavily должен быть устранён восстановлением runtime secret projection.
- `policy_blocked` для Yandex должен быть устранён для free-tier режима.
- Provider waterfall обязан доказать `selected → request_started → response_received` либо точную typed причину отказа.
- Данные должны пройти normalization, Evidence Guard и `used_in_report`; сам успешный вызов provider не закрывает #336.
