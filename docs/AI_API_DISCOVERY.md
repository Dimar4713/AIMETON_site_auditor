# AIMETON Site Auditor API — AI/agent discovery contract

AIMETON exposes API documentation in formats that do not require JavaScript or a graphical browser.

## Stable discovery endpoints

- `GET /llms.txt` — shortest human/AI-readable discovery document.
- `GET /api/capabilities` — compact JSON index of machine-readable API entrypoints.
- `GET /api/docs.txt` — plain-text API guide for sandboxed clients.
- `GET /openapi.json` — authoritative complete OpenAPI contract generated by FastAPI.
- `GET /api/health` — runtime health plus discovery links.
- `GET /docs` — Swagger UI for interactive human use; never required for machine discovery.

## Recommended agent flow

1. Read `/llms.txt` or `/api/capabilities`.
2. Fetch `/openapi.json` for the complete route/schema contract.
3. If the client cannot parse OpenAPI, fall back to `/api/docs.txt`.
4. Read `/api/health` only for deployment/runtime state, not as the full API schema.

## Design constraints

Discovery endpoints are GET-only, return JSON or plain text, require no JavaScript, and expose no secrets. They are intentionally small enough for restricted sandboxes and text-only retrieval tools.

The authoritative API schema remains `/openapi.json`; duplicated text is orientation material, not a second source of truth.
